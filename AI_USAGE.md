# AI Usage Statement

The group used OpenAI Codex to assist with project scoping, checking public data sources, drafting and improving the data-wrangling pipeline and Streamlit dashboard, preparing documentation, and supporting validation and tests. AI assistance also helped incorporate teaching-assistant feedback into the dashboard's recovery narrative and interpretation.

AI-generated suggestions and code were reviewed and tested by the group. The group remains responsible for:

- verifying the data against the original data.gov.sg sources;
- understanding and explaining the code and analysis;
- checking calculations, dashboard controls and interpretations;
- revising generated material and correcting inaccuracies; and
- ensuring the final submission reflects the group's own work and conclusions.

Before submission, the group should add a short list of the main prompts used and note any material corrections made to AI-generated output.
